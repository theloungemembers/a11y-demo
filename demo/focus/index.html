Focus Management

Testing keyboard navigation, tab order, and programmatically moving focus.

Focus Movement

Directing Focus

Clicking the button moves focus to the alert container, which is programmatically focusable due to tabIndex={-1}.

tabIndex={-1}
This container received focus programmatically! Screen readers will announce it now.

Unfocusable Error Message

Clicking the button might scroll things into view, but without tabIndex, focus is lost and screen readers won't read the new content automatically.

No tabIndex
This is an important error, but you can't tab to it or programmatically focus it.

DOM Order

Positive tabindex

Never use positive tabindex. It creates a chaotic, unpredictable reading order.

tabindex > 0
